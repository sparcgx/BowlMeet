備份與還原

完整備份會匯出球聚、球員附加資料、計分卡與個人成績資料。還原支援「智慧合併」、「只新增」與「完全取代」，套用前會自動建立安全快照。

智慧合併：同 ID 資料依 updatedAt 保留較新的版本；不同 ID 會加入。任何還原套用前都會先建立快照。

PWA 安全更新

偵測到新版 Service Worker 時不會直接覆蓋目前執行中的 App；先建立資料快照，再套用更新並重新載入。

尚未檢查更新使用 PWA 套件並以 HTTPS / localhost 開啟時可使用。
