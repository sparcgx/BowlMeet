# v0.4.8-dev.2｜球聚賽制與系列賽排名

## 使用方式

球聚現場 → 球聚系列賽 → 設定賽制與隊伍。

- 個人總分：計算前 N 局（1～6 局）的已完成分數總和。
- 個人平均：以計入範圍的已完成局數計算，排序使用精確比例，顯示至一位小數。
- 團體總分：為每位玩家填入隊伍名稱，同名即同隊；加總該隊所有成員的已完成局數。
- 比賽外的後續局數不納入系列賽，原始分數與現場計分保留。
- 同分並列：1、1、3；沒有完成任何一局者不給名次，0 分視為已完成。
- 缺局時顯示暫定排名及缺局數；團體至少兩隊、每隊人數相同、全員分隊且所有局數完成才標示最終結果。
- 團體某一局全員完成才顯示該局隊伍合計，總分仍包含已完成的個人局數。

「排行榜」選擇單一公開球聚，可查看公開系列賽結果。「分享」選擇「系列賽結果卡」，帶入賽制、名次、總分、平均及完成進度。公開部分只使用已公開的 session，不讀取本機未公開分數；取消公開後不再輸出該場結果。

## 資料與範圍

賽制／隊伍為本機 liveState.seriesRules，與球道安排共存；完整備份／取代還原包含設定。合併還原沿用目前工作區。設定不透過 Sync 同步，另一台裝置需自行設定或取代還原完整備份。停用賽制不刪除分數，完成／重新開啟球聚仍保留設定。

不修改 DB_VERSION=2、Scoring Core、IndexedDB / Supabase schema、PUBLIC / Sync payload。正式 v0.4.7.4 Stable/Freeze、v0.4.8-RC.1 Freeze 保留。此功能不包含於 RC.1，需獨立驗收後再進後續候選版。

## 實機驗收 PENDING

使用 dev.2 隔離 Preview 測試資料：

1. 設定個人三局總分，輸入分數，核對各局、總和與缺局提示。
2. 改平均賽，確認排序及同分並列。
3. 分為至少兩隊，核對總分；人數不齊時有提示。
4. 切換球道／局次，不影響系列賽全場結果。
5. reload、關閉 PWA 再開，賽制／隊伍與成績仍在。
6. 完整備份後以取代模式還原測試資料，確認設定保留。

Preview 雲端停用，因此公開系列賽與分享的 PUBLIC-only 限制由合成公開資料的 CI 驗證；不要求向正式 PUBLIC 上傳測試資料。

自動化 Chromium / Playwright WebKit 不等同真實 iPhone Safari、安裝 PWA 或正式 Supabase。
