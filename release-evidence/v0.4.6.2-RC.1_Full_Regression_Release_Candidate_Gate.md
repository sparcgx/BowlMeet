## R2 Device Finding Carried Into RC

使用者實機結果：
- #1 第一次公開：✅ PASS
- #2 取消公開後「重新公開」沒有展示：❌ FAIL

Root cause：
- 使用者停留於「公開歷史」來源。
- 取消公開後該紀錄變成 `r.public = false`，立即被 `historySource === 'public'` 篩選排除。
- 舊判斷另外以遠端 Session 是否仍存在判定 Republish，但取消公開後遠端 Session 已被移除，狀態來源不正確。

RC.1 Repair：
- 取消公開且本機副本存在時，自動切到「我的紀錄」。
- 公開狀態篩選切到「已取消公開」，確保卡片與「重新公開」立即可見。
- Republish 改用 Public Control tombstone `removed` 判斷。
- 重新公開後若仍停在「已取消公開」篩選，會回到「全部狀態」。
