## R2 Device Finding → RC.1 Repair

R2 實機曾發現：
- First Publish：PASS
- 取消公開後「重新公開」未展示：FAIL

Root cause：
- 使用者停留於「公開歷史」來源。
- 取消公開後該紀錄變成 `r.public = false`，立即被 Public source filter 排除。
- 舊 Republish 判斷以遠端 Session 是否仍存在為依據，但取消公開後遠端 Session 已移除，狀態來源不正確。

RC.1 修正：
- 取消公開且本機副本存在時，自動切到「我的紀錄」。
- 公開狀態篩選切到「已取消公開」，卡片與「重新公開」立即可見。
- Republish 改用 Public Control tombstone `removed` 判斷。
- 重新公開後若仍停在「已取消公開」篩選，回到「全部狀態」。

RC.1 實機重測：**PASS**。
