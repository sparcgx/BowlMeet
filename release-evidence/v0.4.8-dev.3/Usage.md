# v0.4.8-dev.3 — 個人成績趨勢與單局逐格明細

接續 v0.4.8-dev.2 的球道管理與系列賽，不修改凍結的 v0.4.8-RC.1。

## 操作

- 玩家 → 查看：原有 Player Hub 內顯示最近 10／20 局進步摘要。
- 玩家 → 分析：保留原有趨勢圖、PB、月平均與逐格統計，增加相同進步摘要。
- 成績紀錄總表、玩家歷史、分析成績表、本場明細：點擊單局分數，開啟唯讀明細。
- 明細包含 10 格、每球符號、倒瓶數、累計；第 10 格符合條件時顯示加投。關閉／Escape 返回原分數焦點。

## 資料口徑

- 最近 10／20 局對比前 10／20 局，兩個不重疊區間皆滿額才顯示變化；不足時標示樣本數及待累積局數。
- 摘要使用該玩家全部歷史的最近局數，不隨分析頁區間篩選改變；介面有明示。
- 玩家身份、同 Session ID 去重與本機優先沿用既有規則。來源僅有公開資料時不回填其他本機資料。
- 舊紀錄只有總分時不虛構逐格資料；未完成逐格與逐格／總分不一致亦明示。
- 原有 PUBLIC-only 排行榜、分享卡與公開控制不變。
- 此功能不新增持久化欄位；Scoring Core、IndexedDB／Supabase schema、PUBLIC payload、Sync、Backup／Restore 不變。
