Date: 2026-09-26

ISSUE
- 下方選單與「更多」內選單發生位移。

ROOT CAUSE
1. Mobile Dock 實際只有 4 個主要按鈕，但 dev.3 override 強制 5 欄。
2. Dock / Backdrop / More Sheet 位於可被 90–120% layout scale zoom 的 .app 內，iPhone fixed positioning 可能一起偏移。

FIX
- Dock 固定 4 等分欄。
- Dock / Backdrop / More Sheet 啟動時 mount 到 body，脫離 .app zoom 座標系。
- 更多選單直向 3 欄；最後「設定」滿寬收尾。
- <=420px 改 2 欄；短螢幕橫向改 4 欄。
- PWA cache 更新為 dev.3-r1。
