# BowlMeet v0.4.7.4-dev.2｜Data Safety Recovery & Persistence Hardening

日期：2026-09-30  
狀態：**Native Data Safety Fault Gate PASS / Regression Gate pending final identity run / Draft**

## 修正來源
dev.1 的原生故障注入在 Chromium 與 WebKit 各 24 情境中僅 7 PASS / 17 FAIL。dev.2 針對已重現的資料保存缺陷修復，不修改 DB_VERSION、Supabase Schema 或 PUBLIC payload。

## 修正
- 啟動前驗證 IndexedDB appState 結構；不合法狀態不得覆蓋合法 localStorage。
- 啟動協調比較資料內 record-level timestamps；較新的本機分數、session、draft、removed tombstone 不再被較舊 IDB 直接覆蓋。
- localStorage JSON 解析損壞會留下 corruption signal；存在合法 IDB 時由 IDB 恢復。
- localStorage 寫入與 IndexedDB queue 解耦；QuotaExceededError 不再阻止 IDB 備援。
- 多 key mirror 發生中途錯誤時回滾已寫入 key，並排程完整狀態寫入 IDB。
- idbPut / idbPutMany / idbDelete 補上 transaction.onabort reject。
- 新增 storageHealth；兩條持久化路徑未確認時顯示「資料尚未安全儲存」，不再誤報已保存。
- DB_VERSION 維持 2；無 schema migration。

- Stable / Freeze / main 未因本修正改動。
